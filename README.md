# Pillage Unity

Unity project for Pillage.

## Requirements

- Unity 6000.3.11f1

## Getting Started

1. Clone this repository.
2. Open the project folder in Unity Hub.
3. Use Unity 6000.3.11f1 or install it from Unity Hub if needed.
4. Open a scene from `Assets/Scenes`.

## Project Structure

- `Assets/` - Game assets, scripts, scenes, and prefabs.
- `Packages/` - Unity package manifest and lock file.
- `ProjectSettings/` - Unity project settings.
